# Projeto Questões Autorais

Sistema para criar questões autorais com interface intuitiva.

## Como usar

### Option 1: Com servidor Python (rápido)
```bash
npm start
# Acesse http://localhost:8000
```

### Option 2: Com Vite (desenvolvimento)
```bash
npm install
npm run dev
```

## Estrutura do Projeto

```
src/
├── pages/       - Páginas HTML
├── components/  - Componentes JSX
├── styles/      - Arquivos CSS
├── scripts/     - Scripts JavaScript
└── images/      - Imagens e SVGs
```
